# Cambium docs index

Index for the `docs/` tree.

## docs/architecture/

- [`architecture.md`](architecture/architecture.md) — current-versus-target contract; source and tests establish current behavior while the document names targets.
- [`system-design.md`](architecture/system-design.md) — historical v0.1.0 pre-implementation system design draft and its review record, not runtime authority.
- [`user-cli.md`](architecture/user-cli.md) — current CLI behavior; `src/cambium/cli.py` and the scenario tests are the authority.
- [`module-template/`](architecture/module-template/) — normative module template (module architecture, dataset format, example spec) for new modules under `src/cambium/modules/`.
- [`reviews/`](architecture/reviews/) — historical pre-implementation adversarial reviews (distributed systems, implementation readiness, LLM/agent architecture).

## docs/research/

Experiments, evidence, and design history. See
[`research/README.md`](research/README.md) for the authority order and the
complete file index.
