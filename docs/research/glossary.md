# Cambium Glossary — Naming Map

This map bridges Cambium's Latin architecture names and current plain-English
names. `docs/architecture/architecture.md` is authoritative; `system-design.md`
and `agents.md` provide history and repository vocabulary. FB4 #1 retained the
Latin names, so research references remain searchable here.

Provider tiers are normally lowercase in configuration and wire data
(`fast`, `balanced`, `strong`, `reasoning`); uppercase names the tier family.

**Runtime labels:** **Current** means a checked-in callable path; **target**
means architecture or a disconnected pure helper. `run_plan` currently
dispatches a flat task list; no `NodeSession` symbol or production caller
exists.

| **Opifex (M5)** | Worker runtime for one node: coding loop, tools, heartbeats, checkpoints, and result/exit messages. | `docs/architecture/architecture.md` §§2, 4, 7.6; `src/cambium/worker.py` | Worker; worker runtime; v0.1 `WorkerAgent` / `worker.py` |
| **Nuntius (M1)** | Newline-delimited JSON IPC and `request_id` correlation, without workflow policy. | `docs/architecture/architecture.md` §5; `src/cambium/ipc.py` | IPC; protocol; messenger; v0.1 newline-delimited JSON |
| **Unio (M7)** | Serialized merge sequencer: stage, gate, and atomically publish a worker result to `refs/heads/main`. | `docs/architecture/architecture.md` §§4, 7.8; `src/cambium/merge.py` | Merge; merge sequencer; v0.1 `MergeSequencer` |
| **Surculus (M3)** | Worktree create/recover/prune/list and generation updates; plumbing is split across runtime and merge code. | `docs/architecture/architecture.md` §§4, 7.5; `src/cambium/supervisor.py`, `src/cambium/merge.py` | Worktree manager; v0.1 `WorktreeManager` |

| **Task tree** | **Current validator/helpers; target scheduler:** per-session DAG with one root, parent links, bounded depth/width, and wave scheduling. `run_plan` does not use these helpers for DAG dispatch. | `docs/architecture/architecture.md` §3.7 and I2.1–I2.5; `src/cambium/tasktree.py`; `docs/research/architectus-design.md` §2 | `TaskTree`; task DAG; v0.1 flat subtask list; `depends_on` (legacy prose: `requires`) |
| **NodeSession** | **Target only:** checkpointed sub-session owned by one task-tree node; no `NodeSession` symbol or caller exists. | **Generation / fencing** | Monotonic per-task spawn number; stale workers exit before git or state writes. | `docs/architecture/architecture.md` §7.3; `src/cambium/fencing.py`, `src/cambium/supervisor.py` | Fencing token; generation counter; stale-worker fence; split-brain guard |

| **I2.1 — Single root** | **Current validation; target dispatch:** exactly one root; every non-root has one `parent_task_id`. | `docs/architecture/architecture.md` §3.7 I2.1; `src/cambium/tasktree.py` `build_tree()` | One-root rule; root invariant |
| **I2.2 — No cycles** | **Current validation; target dispatch:** acyclic, no self-loops, and no multi-parent nodes; checked before any future DAG scheduler. | `docs/architecture/architecture.md` §3.7 I2.2; `src/cambium/tasktree.py`; `docs/research/feedback-4-assessment.md` claim 6 | Cycle detection; acyclic plan; D2 DAG invariant |
| **I2.3 — Depth and width bounds** | **Current build checks; target DAG admission:** `max_depth` and `max_width` bound nesting and fan-out. | `docs/architecture/architecture.md` §3.7 I2.3; `src/cambium/tasktree.py`, `src/cambium/supervisor.py` | Tree bounds; fan-out limit; concurrency cap |
| **I2.4 — Context composition** | **Target rule:** a node would receive bounded own history, parent summary, and subtree envelopes, not sibling raw sessions. Current `subtree_of()` is a pure helper; `run_plan` does not compose this context. | `docs/architecture/architecture.md` §3.7 I2.4 and §6.6; `src/cambium/tasktree.py`, `docs/research/architectus-design.md` §§3.1–3.5 | Context composition; sibling isolation; bounded context rule |
| **I2.5 — Tree-level completion** | **Target rule:** a node would complete after its work and every child envelope; current `PlanResult` aggregates flat `run_plan` tasks. | `docs/architecture/architecture.md` §3.7 I2.5 and §7.1; `docs/research/architectus-design.md` §2.3; `src/cambium/supervisor.py` | Recursive completion; subtree completion; root completion rule |
| **I2.6 — Append-only session logs** | **Target node rule:** steering and observations append turns; current conversation storage is not a `NodeSession` runtime. | `docs/architecture/architecture.md` §3.7 I2.6 and §6.6; `docs/research/architectus-design.md` §3.2 | Append-only history; conversation log; immutable session history |
| **I2.7 — Information hiding** | **Current helper; target integration:** child-to-parent messages contain only result-envelope keys, never scratchpads or reasoning traces. | `docs/architecture/architecture.md` §3.7 I2.7 and §5.2; `src/cambium/tasktree.py` | Envelope-only upward flow; scratchpad isolation; information-hiding invariant |

| **Circuit breaker states** | Provider health states: `UNKNOWN`, `HEALTHY`, `COOLDOWN`, `OPEN`, `HALF_OPEN`, `DISABLED`; the sliding-window extension is in cascade research. | `docs/architecture/architecture.md` §9.1–9.2; `docs/research/cascade-design.md` §§2.3–2.4 | Provider health; breaker; outage circuit; cooldown state |

| **Gate** | Deterministic verification command; pass reaches `DONE`, failure permits bounded steering, and merge has a final gate. | `docs/architecture/architecture.md` §§7.1, 7.8, 7.9; `src/cambium/supervisor.py`, `src/cambium/merge.py` | Test gate; verification gate; D4 gate; gate verdict |
| **Approval primitive** | **Current command control:** `ApprovalGate` classifies commands and tools enforce unsafe-git/shell approval; it is not a separate production session gate. | `src/cambium/approval.py`, `src/cambium/tools.py` | Command policy; host callback boundary; approval gate |
| **Blackboard / `shared.db`** | Planned SQLite-WAL shared-facts store; Architectus writes validated proposals at wave boundaries while ordinary tasks retain I2.4 isolation. | `docs/research/architectus-design.md` §3.6; `docs/architecture/architecture.md` §16.2 | Blackboard; `_shared` context segment; shared context store; not `conversations.db` |
| **`include_diff`** | Per-task envelope flag: default includes a capped diff; `false` omits it but retains truncation and changed-file metadata. | `docs/research/feedback-4-assessment.md` claims 7 and 21; `docs/research/architectus-design.md` §§0.3, 3.7; `src/cambium/tasktree.py` | Diff inclusion flag; diff payload switch; unified-diff opt-out |
