# Cambium Glossary — Naming Map

This map bridges Cambium's Latin architecture names and current plain-English
names. `docs/architecture/architecture.md` is authoritative; `system-design.md`
and `agents.md` provide history and repository vocabulary. FB4 #1 retained the
Latin names, so research references remain searchable here.

Provider tiers are normally lowercase in configuration and wire data
(`fast`, `balanced`, `strong`, `reasoning`); uppercase names the tier family.

**Runtime labels:** **Current** means a checked-in callable path; **target**
means architecture or a disconnected pure helper. `run_plan` currently
dispatches a flat task list; no `NodeSession` symbol or production caller
exists.
